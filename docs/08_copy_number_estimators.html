Introduction

In this week’s task, we will examine and compare four kinds of estimates for the number of copies of a cell.

We will try to highlight the pros and cons of each method and also check their influence on different areas of the chromosome, considering the logic of the GC effect.

Setup - Preliminary part

To make the process easier, we added 0 values to each file to represent 0 reads in a cell or 0 GC count in every cell. This is only for the purpose of ensuring equal cell size along the entire 250M length of the chromosome.

We will eventually clean the data and remove outliers so that the illogical parts (0 GC count in every cell) will not matter.

As requested, we created 100k cells for the cancer sample and healthy sample, each cell containing 2.5k bases, and did the same for the GC content.

# Pad each dataset with zeros to reach 2.5 million elements
desired_length <- 2500000

# Function to pad a vector with zeros
pad_with_zeros <- function(data, desired_length) {
  current_length <- length(data)
  if (current_length < desired_length) {
    data <- c(data, rep(0, desired_length - current_length))
  }
  return(data)
}

# Apply padding to each dataset
GC_100 <- pad_with_zeros(GC_100, desired_length)
reads_100_A1 <- pad_with_zeros(reads_100_A1, desired_length)
reads_100_B1 <- pad_with_zeros(reads_100_B1, desired_length)


# Function to sum every 'n' elements into a new vector
sum_every_n <- function(data, n) {
  new_length <- length(data) %/% n
  new_data <- numeric(new_length)
  for (i in 1:new_length) {
    start_idx <- (i - 1) * n + 1
    end_idx <- i * n
    new_data[i] <- sum(data[start_idx:end_idx])
  }
  return(new_data)
}

# Sum every 25 elements for each dataset
new_GC_100 <- (sum_every_n(GC_100, 25))/25
new_reads_100_A1 <- sum_every_n(reads_100_A1, 25)
new_reads_100_B1 <- sum_every_n(reads_100_B1, 25)

# One sample GC corrcet 
one_sample_correct = function(samp, preds, eps) {
  one_correct = (samp+eps)/(preds+eps)
  adj_med = 1/median(one_correct)
  return(adj_med * one_correct)
}

eps = 1

# The 25m -30m case
corrected_health_25m_30m = one_sample_correct (loc_25m_30m$Reads_B1,loc_25m_30m$predicted_values_health,eps)

uncorrected_health_25m_30m = one_sample_correct(loc_25m_30m$Reads_B1,rep(1,length(loc_25m_30m$Reads_B1)),eps)


corrected_cancer_25m_30m = one_sample_correct (loc_25m_30m$Reads_A1,loc_25m_30m$predicted_values_can,eps)

uncorrected_cancer_25m_30m = one_sample_correct(loc_25m_30m$Reads_A1,rep(1,length(loc_25m_30m$Reads_A1)),eps)

# Two sample correction function
two_sample_correct_e = function(tumor, normal,eps = 1) {
  two_correct = (tumor+eps)/(normal+eps)
  two_correct_aft_med = two_correct/median(two_correct,na.rm=TRUE)
  return(two_correct_aft_med)
}

Results Explanations:

When we look at the results of the “Two sample” methods, we find that some areas we might have thought were problematic (like the 26.8M area) are “canceled out” by the estimation noise combined from both samples, which might disqualify it as a problematic area in terms of the number of copies.

On the other hand, we revealed that the 28.75M area, even with the GC effect taken into consideration, is lower than the expected value of one copy, which might indicate a true copy number problem in this area of the chromosome.

Part B - Quantitative measure \(MAD\)

As a quantitative measure, we chose the \(MAD\) - mean absolute deviation.

What it does is take the “a” estimates we got, subtract 1 from each, and then take the absolute value (because we don’t care in which direction it deviates from 1 right now, just that it is far from 1).

We did this only for the Two sample methods: with and without GC correction.

# Function to calculate MAD for each cell
calculate_mad_per_cell <- function(observed, expected) {
  mad_per_cell <- abs(observed - expected)
  return(mad_per_cell)
}

Part C - Pros & Cons

  • Correcting a single sample for GC content helps fix distortions in read counts caused by varying GC content in the DNA.It’s also pretty easy and straightforward since it involves just one sample.However,it only corrects biases in that one sample, and only depends on it, which might not reflect broader trends.

  • Comparing two samples without GC correction highlights differences in copy number variations, canceling out some systematic biases,mostly useful for comparing conditions like cancer vs. healthy.However, GC bias remains unaddressed, potentially affecting the results.

  • Correcting two samples for GC content before comparing them handles well with both within-sample and between-sample biases, making it great for comparing cancer vs. healthy. However, it’s more complex and time-consuming, requiring extra computational resources.

  • When we want to take a look on application to other chromosomal areas,and if our analysis is correct, we believe that the two-sample method revealed the 28.75M area, which we probably would not have found without it. The problem with these methods is that we are not sure if the elimination of the 26.8M area as a problematic area, which we identified in the first method, is a correct elimination.

Short summary

This week’s lab really emphasizes the importance of choosing the estimation model that we believe is most relevant to our case.

For example, in the 28.75M area, we can’t say for sure that it’s an area with a shortage of helices if we are not completely sure of our process, our assumptions, and our estimation model.
