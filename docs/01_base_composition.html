Part B: function for the number of appearances of the bases in the cell

We first determined the total length of the genome.

We then iterated over the genome in increments equal to the specified cell size.

Within each segment, we use sapply along with charToRaw to compare each character against the DNA bases,counting their occurrences in each cell.

Finally, our function returned this list of base counts which we will apply on the genome with cell defined to size 1000.

Of course, we will not display the 20,000 cases as a table because it will not be clear, and therefore in Part C, we will use the function to display each basis histogram.

# set up the function 
sum_bases_in_cells <- function(genome, cell_size) {
  genome_length <- nchar(genome)
  
  # Initialize list to store results
  base_counts_per_cell <- list()
  
  # Iterate over the genome by cell_size
  for (start in seq(1, genome_length, by = cell_size)) {
    end <- min(start + cell_size - 1, genome_length)
    cell <- substring(genome, start, end)
    
    # Count bases in the cell
    counts <- sapply(c("A", "C", "G", "T"), function(base) {
      sum(charToRaw(cell) == charToRaw(base))
    }, USE.NAMES = TRUE)
    
    # Append counts to the list
    base_counts_per_cell[[length(base_counts_per_cell) + 1]] <- counts
  }
  
  return(base_counts_per_cell)
}

base_counts <- sum_bases_in_cells(chr1_str_30M_50M, 1000)

# Function to plot histograms and show descriptive statistics 
plot_base_histograms <- function(base_counts, base) {
  counts <- sapply(base_counts, "[[", base)
  if (base == "A") {
    counts <- counts[counts != 1]
  } else {
    counts <- counts[counts > 0]
  }

  # Create histogram 
  hist_obj = hist(counts, breaks=50, xlab = paste(base, "Count"), ylab = "Frequency",
       main = paste("Distribution of", base, "in Bins"), col = "skyblue", border = "black")
  
  # Calculate descriptive statistics
  stats <- c(
    Min = min(counts),
    Q1 = quantile(counts, 0.25),
    Median = median(counts),
    Mean = mean(counts),
    Q3 = quantile(counts, 0.75),
    Max = max(counts),
    SD = sd(counts)
  )
  
  # Format statistics as text
  stats_text <- paste(names(stats), format(stats, digits = 3), sep = ": ", collapse = "\n")
  
  cat("\nStatistics for", base, ":\n", stats_text, "\n\n")
}

# The Chromosome 1
genome <- chr1_str_30M_50M 

# Define bin size and calculate number of bins
bin_size <- 2000
genome_length <- nchar(genome)
n_bins <- ceiling(genome_length / bin_size)

# Initialize matrix to store counts of each base per bin
let_count <- matrix(0, nrow = n_bins, ncol = 4)
colnames(let_count) <- c("A", "C", "G", "T")

# Count bases in each bin
for (i in 1:n_bins) {
  start_bin <- 1 + (i - 1) * bin_size
  end_bin <- min(i * bin_size, genome_length)
  segment <- substring(genome, start_bin, end_bin)
  
  for (let in 1:4) {
    let_count[i, let] = sum(charToRaw(segment) == charToRaw(colnames(let_count)[let]))
  }
}

# Change the margins and set up for multiple plots
par(mfcol = c(4,1), mar = c(1, 0, 0, 0), oma = c(5, 4, 0, 0))

# Plotting each base frequency
for (i in 1:4) {
  plot(seq(0, genome_length, by = bin_size) / 1e6, let_count[,i]/bin_size, pch = 20, cex = 0.5,
       xlab = ifelse(i == 4, "Location on Chromosome (Millions)", ""), 
       ylab = "", yaxt = 'n', main = "")  
}

# Adding a central X-axis label
mtext("Location on Chromosome (Millions)", side = 1, outer = TRUE, line = 3)

# Adding a central Y-axis label for the entire plot
mtext("Frequency", side = 2, outer = TRUE, line = 3)

Results Explanations:

It can be seen that in general the variation here is relatively high.

Bases A & T have the highest variance,base G has a slightly lower variance and base C has the lowest variance.

If we look at the general trend, it seems that the location of the points has a fairly similar structure, that is, the change of the points may not be at the same level of spread in the different bases, but they do maintain some sort of continuous trend.

# Convert the let_count matrix to a data frame for easier manipulation
base_counts_df <- as.data.frame(let_count)

# Initialize a list to store outlier indices for each base pair
outlier_indices_list <- list()

# Set up a 2x3 plot layout for the 6 unique combinations
par(mfrow = c(2, 3), mar = c(4, 4, 2, 1))

# Plotting loop for each unique base combination
for (i in 1:3) {
    for (j in (i+1):4) {
        plot(base_counts_df[,i], base_counts_df[,j], 
             xlab = "", ylab = "", 
             main = paste(colnames(base_counts_df)[i], "vs", colnames(base_counts_df)[j]),
             pch = 20, col = rgb(0, 0, 1, 0.5), cex = 0.6)

        # Linear regression line
        model <- lm(base_counts_df[,j] ~ base_counts_df[,i])
        abline(model, col = "green")

        # Calculate and sort residuals
        residuals <- abs(resid(model))
        sorted_indices <- order(-residuals) 

        # Highlight the next top 5 residuals in deep pink (positions 2 to 6)
        if (length(sorted_indices) > 6) { 
            top_5_indices <- sorted_indices[2:6] # Skip the (0,0), select the next five
            points(base_counts_df[top_5_indices, i], base_counts_df[top_5_indices, j], 
                   col = "deeppink", pch = 20, cex = 0.9)

            key <- paste(colnames(base_counts_df)[i], colnames(base_counts_df)[j], sep="_")
            outlier_indices_list[[key]] <- top_5_indices
        }
    }
}

A. What is the trend?

In terms of theory, we would expect to see a negative trend for each pair of bases - that is, if we were to draw the multinomial distribution with the expectation of an equal amount of bases in each cell - the correlation would necessarily be negative.

Based on our data, it doesn’t seem to be the case for every base pair - which could indicate other features beneath the surface.

As expected, we found out that for bases that do not form a pair (like A-C for example) there is a negative correlation, but for the combination of the pairs C-G (in A-T it is less clear what the trend is) we actually received a positive correlation.

For the A-T Combinations we can see that for smaller value there is a positive correlation and for bigger values there is a negative one,again as expected.

Note: We did not consider the (0,0) point as an outlier because this point is irrelevant in our opinion.

Part F: Base pairs that behave “similarly” in our eyes

We believe that the pairs with “similar” behavior are A-T and C-G.

We know that this is perhaps an obvious choice in terms of the logic of the DNA’s behavior, but also in terms of all the elements tested in this task (identical histograms, similar distribution on the position on the chromosome and even the position of the outliers), we can quite clearly see the similarity in their behavior.
